Learning to Denoise — DDPM and the Loss That Trains Every Image Model

The reverse of destruction is generation — but only if a network can learn to run one small step of the destruction backwards. The surprise at the heart of DDPM is how plain the training recipe turned out to be: corrupt an image, ask the network which noise was added, score it with mean squared error. No adversary, no instability — a regression loss so simple it reads like a tutorial exercise, hiding a derivation that connects it to maximum likelihood.

Small Gaussian forward steps make each reverse step approximately Gaussian — so generation reduces to regression. DDPM's recipe: predict the added noise, score it with plain mean squared error, sample by walking the chain backwards with fresh noise injected each step. Four lines of training loop, and why they beat the trilemma.

Webhook Security — Signatures, Replay Windows, and the Attack Surface Nobody Audits

A webhook endpoint is a public URL that accepts POSTs and changes state in your systems — which is to say, it's an unauthenticated write API unless you make it otherwise. The security model is well understood and regularly skipped: verify signatures correctly (several popular ways to do it wrong), bound the replay window, and remember that on the provider side, delivering webhooks means making HTTP requests to arbitrary customer URLs — an SSRF machine by design. This post covers both directions of the attack surface.

Receivers: HMAC over raw bytes, constant-time, scheme-aware, rotatable secret lists; signed-timestamp replay windows; fail closed loudly — and schema-validate anyway. Providers: webhook delivery is SSRF by design — resolve-validate-pin destinations, egress-isolate workers, bound and never echo responses.

Backfills at Scale — Rewriting a Billion Rows Under Live Traffic

The expand phase created an empty column; something has to fill it for a billion existing rows while production traffic continues oblivious. Backfills are the manual labor of migrations — conceptually trivial, operationally where migrations actually spend their calendar time and take their production risks. The craft is entirely in the adverbs: incrementally, throttled, resumably, idempotently.

Backfills are made safe by four adverbs: incrementally (keyset-walked, time-sized, per-batch-committed), throttled (a control loop yielding to replication lag, content to take days), resumably (transactional checkpoints), idempotently (absolute writes, safe re-runs). The transform is reviewed code with a verify-only mode.
